# Keyboard Shortcuts

## Working on images

| Key | Action |
|---|---|
| `A` / `D` | Previous / next image |
| `P` | Polygon tool |
| `N` | Edit Points tool |
| `S` | SAM Segment tool |
| `M` | Measure Distance tool |
| `C` | Grid calibration |
| `Delete` | Delete the selected annotation |
| `Esc` | Cancel the current tool or discard a pending shape |

Tool keys `P`, `N` and `S` work in Pixel Level mode.

## While drawing

| Key | Action |
|---|---|
| `Backspace` | Remove the last corner of a polygon (Polygon tool) |
| `Enter` | Accept the suggested SAM outline (SAM tool) |
| `Esc` | Cancel |

## Center Crop calibration

| Key | Action |
|---|---|
| Arrow keys | Move the crop 1 px |
| `Shift` + arrow keys | Move the crop 10 px |

## Mouse

| Action | Result |
|---|---|
| Scroll | Zoom |
| Right-click and drag | Pan |

## Menus

| Key | Action |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save project as |
| `Ctrl+Q` | Exit |
